# Site da EcoModa
# EcoModa — Moda que Transforma

## Sobre o projeto

O EcoModa é uma solução digital desenvolvida para o
Instituto EcoModa Sustentável, uma ONG e marca autoral
de moda sustentável.

## Problema

A EcoModa realizava suas vendas principalmente por
feiras, eventos e mensagens privadas no Instagram.

Com o crescimento da produção, esse processo passou a
gerar dificuldades para a equipe, principalmente na
consulta de disponibilidade, cálculo de frete e
organização dos pedidos.

## Solução

Foi desenvolvido um e-commerce responsivo para:

- apresentar as peças disponíveis;
- organizar o catálogo;
- facilitar a compra;
- apresentar informações sobre cada produto;
- mostrar a artesã responsável pela produção;
- apresentar o impacto social e ambiental.

## Público-alvo

Consumidores interessados em:

- moda sustentável;
- consumo consciente;
- produtos artesanais;
- impacto social.
